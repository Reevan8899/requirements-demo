# Глоссарий

| Термин | Определение |
|---|---|
| Заметка | Запись с заголовком, текстом, ID и датами создания и изменения. |
| ID заметки | Уникальный идентификатор UUID в шестнадцатеричной записи. |
| Хранилище | Локальный JSON-файл с заметками. |
| Атомарность | Читатель получает старый или полностью записанный новый файл. |
| SRS | Спецификация требований к программному обеспечению. |
| RTM | Матрица связей требований с задачами, кодом, коммитами, тестами и статусом. |
| MoSCoW | Приоритеты Must have, Should have, Could have и Won't have. |
| CI | Автоматические проверки изменений при push и в pull request. |
