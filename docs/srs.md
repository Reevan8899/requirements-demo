# Спецификация требований (SRS)

**Проект** — Менеджер заметок  
**Версия** — 1.0  
**Дата** — 8 ноября 2026 г.  
**Автор** — Reevan8899

## 1. Назначение

Спецификация определяет поведение и характеристики локального консольного менеджера заметок. Ею пользуются разработчик, тестировщик и принимающий работу.

## 2. Общее описание

Владелец заметок работает через русскоязычный CLI. Приложение сохраняет данные в JSON-файле и работает без сети после установки зависимостей. Доступ к данным определяется учётной записью операционной системы. Режим `0600` проверяется на POSIX.
