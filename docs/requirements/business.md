# Бизнес-требования

## BR-001: Автономность пользователя

**Приоритет** — Must have  
**Источник** — Спонсор проекта

Владелец может вести заметки без подключения к интернету после установки приложения. Приёмка проходит на локальном хранилище с заблокированными сетевыми подключениями.

## BR-002: Простота использования

**Приоритет** — Must have  
**Источник** — Спонсор проекта

Новый пользователь без предварительного инструктажа должен создать, найти и отредактировать заметку за пять минут. Для приёмки фиксируется время выполнения сценария реальным пользователем.

## BR-003: Расширяемость

**Приоритет** — Should have  
**Источник** — Архитектор

Добавление форматов экспорта, например PDF и DOCX, должно выполняться через отдельные адаптеры, получающие заметки из публичного API. Приёмка показывает, что отдельный тестовый адаптер читает поля заметки через этот API без изменения ядра.
