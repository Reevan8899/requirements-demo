# Нефункциональные требования

## NFR-001: Производительность списка

**Категория** — Производительность  
**Приоритет** — Must have  
**Реализует** — BR-002

`note list` читает и выводит список из 10 000 коротких заметок за 500 мс или быстрее. Тест измеряет вызов CLI с перенаправленным выводом, без времени запуска интерпретатора и подготовки файла.

## NFR-002: Атомарность хранения

**Категория** — Надёжность  
**Приоритет** — Must have  
**Реализует** — BR-001

При сбое процесса до атомарной замены сохраняется предыдущая версия JSON. Параллельные изменения сериализуются блокировкой файла. Ошибка записи сопровождается подсказкой.

## NFR-003: Права доступа к хранилищу

**Категория** — Безопасность  
**Приоритет** — Should have  
**Реализует** — BR-001

На POSIX создаваемый или заменяемый файл хранилища имеет режим `0600`. Проверка выполняется на Linux.

## NFR-004: Русскоязычные ошибки

**Категория** — Удобство использования  
**Приоритет** — Must have  
**Реализует** — BR-002

Ошибки ввода, разбора команды и доступа к хранилищу выводятся на русском языке, содержат подсказку и сопровождаются ненулевым кодом выхода.

## NFR-005: Покрытие тестами 80%

**Категория** — Сопровождаемость  
**Приоритет** — Should have  
**Реализует** — BR-003

Покрытие строк в `src` по pytest-cov составляет не менее 80%. GitHub Actions завершается ошибкой при нарушении порога.

## NFR-006: Внешний файл локализации

**Категория** — Локализация  
**Приоритет** — Could have  
**Реализует** — BR-003

Сообщения интерфейса находятся в `src/messages_ru.json`. Этот файл входит в устанавливаемый пакет.
