# Функциональные требования

## FR-001: Создание заметки

**Приоритет** — Must have  
**Реализует** — [UR-001](user.md#ur-001-создание-заметки)

`note add --title "Заголовок" --body "Текст"` сохраняет заметку и сообщает её ID. Заголовок содержит до 100 символов, тело — до 10 000. Пустые и состоящие только из пробелов значения отклоняются с подсказкой.

## FR-002: Список заметок

**Приоритет** — Must have  
**Реализует** — [UR-002](user.md#ur-002-просмотр-списка-заметок)

`note list` выводит для каждой заметки ID, заголовок и дату создания. Для пустого хранилища выводится сообщение «Заметок пока нет».

## FR-003: Поиск заметок

**Приоритет** — Should have  
**Реализует** — [UR-003](user.md#ur-003-поиск-по-заметкам)

`note search --query "слово"` ищет подстроку в заголовке и тексте без учёта регистра. Для пустого запроса выдаётся подсказка. Если совпадений нет, об этом сообщается явно.

## FR-004: Редактирование заметки

**Приоритет** — Should have  
**Реализует** — [UR-004](user.md#ur-004-редактирование-заметки)

`note edit ID --title "Новый заголовок" --body "Новый текст"` принимает один или оба флага. Правила валидации совпадают с FR-001. ID и дата создания сохраняются, дата изменения обновляется. Для неизвестного ID выводится подсказка.

## FR-005: Удаление заметки

**Приоритет** — Could have  
**Реализует** — [UR-005](user.md#ur-005-удаление-заметки)

`note delete ID` запрашивает подтверждение. Ответ «да» удаляет запись, другие ответы и завершение ввода отменяют операцию. Неизвестный ID вызывает ошибку с подсказкой.
